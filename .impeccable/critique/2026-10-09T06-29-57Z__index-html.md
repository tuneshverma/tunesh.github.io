# Priority Issues

## [P0] Voice agent invisible and un-startable on work.html; phantom keyboard stop on both pages
Re-verified by parent. placeFab() returns early with no .va-anchor; work.html has none. Measured: transform matrix(1,0,0,1,-9999,-9999), opacity 1, pointer-events auto, visibility visible - the only focusable off-screen element on the page. Repaints a canvas at -9999px forever (720 fill calls in 3s).
Why: the differentiator is absent from the page where interest peaks, and a keyboard user tabs onto an invisible control that opens a modal and requests their microphone.
Fix: add .va-anchor to work.html (slot between hero and #praxispro; .va-anchor + section{border-top:0} already handles the divider). Harden placeFab() to fall back to docked instead of returning. Gate focusability on visibility, not opacity.
Command: $impeccable harden

## [P1] Home page is blank without JavaScript
Verified with screenshot: 30 of 30 .reveal elements compute to opacity 0, no <noscript>. A nav bar over empty black.
Why: locked-down corporate laptops, strict CSP, in-app browsers and link-preview renderers show a recruiter nothing.
Fix: invert the default. .reveal{opacity:1;transform:none}, scope animation behind .js .reveal{...}, set documentElement.classList.add('js') as the first inline statement.
Command: $impeccable harden

## [P1] Every heading below h1 runs at body leading
Measured: h1 92px/87.4px (0.95). h2 42px/67.2px, h3 27px/44.55px - all inheriting line-height 1.6. No heading below h1 sets its own. On mobile a 42px heading with 67px leading reads as two separate headings. This is why work.html scans as an undifferentiated wall.
Fix: .section-head h2{line-height:1.05}, .case h3{1.15}, .card h3{1.25}, .job h3{1.3}. Highest-leverage change on the site.
Command: $impeccable typeset

## [P1] Responsive fails twice: no mobile nav, and an 800-1000px collapse band
No mobile navigation: @media(max-width:850px){.navlinks{display:none}} with no replacement. work.html loses all 8 links including Home; a 24x26px "TV." mark is the entire nav for ~27 screens.
Collapse band: .section-head is a flex row whose heading child has no min-width. 801px -> h2 244px/5 lines; 834px (iPad portrait) -> 255px/4 lines; 900px -> 310px/3 lines. At 834px the heading is narrower than its own subtitle, and "500ms-1.6s" splits across two lines in its metric card.
Tap targets: six "View case studies" links measure 121x19px against a 44px minimum.
Fix: raise block-stacking to ~1000px or make .section-head a grid (minmax(380px,1fr) minmax(0,480px)). white-space:nowrap on .metric strong; 2-col metrics below 950px. Pad .case-link. Add a mobile nav. section[id]{scroll-margin-top:96px} (currently 0 against a 72px sticky nav).
Command: $impeccable adapt

## [P2] Structural borders at 1.33:1; clickable visually identical to static
--line #202733 on --bg = 1.33:1 against WCAG 1.4.11's 3:1, and it draws every structural edge on the site. Footer #697382 = 4.15:1 at 12px, below AA - the only text contrast failure on either page (--muted 7.18:1, --accent2 12.87:1 all pass). .btn/.card/.tagpill share one border token and one fill. .sub and .role in #7c8cff look like links and are not; .case-link in teal is.
Fix: lift --line to ~#333c4b (~3.1:1) - one token repairs every edge. Lift the footer to --muted. Split the token: quiet hairline for containers, brighter border + hover for actionable surfaces. Reserve violet for clickable.
Command: $impeccable colorize
